# w3m3

A take on the [#MillionMaskMovement](https://millionmask.org/drawboard) drawboard.

Draw the front of your mask, then name **3 words you show** and **3 words you usually hide**. Those six words are part of the mask itself — always on screen, required to submit.

## Run

```bash
npm install
npm run dev
```

## MVP tools

Pen · Eraser · Fill · Line · Rect · Oval · Undo/Redo · Clear · named color palette · size presets · mask outline guide
